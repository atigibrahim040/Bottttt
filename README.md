# Bottttt - Advanced Telegram Automation

This script is strictly tailored to parse:
- `FAABOT@ 7DD` (Sends code to @FAABOT)
- `https://t.me/yynnurybot?start=...` (Sends /start payload to @yynnurybot)
- Joins required channels (e.g., `https://t.me/wa_wa_el`) and clicks "Verify" buttons.
- Human delay: 7-10 seconds.
